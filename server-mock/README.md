# Mock Backend Server

Изолированный mock-бэкенд для разработки фронтенда.

## Установка

```bash
cd server-mock
npm install
```

## Использование

### Заполнение базы данных

```bash
npm run seed
```

Создаст 3 пользователя с разными ролями и 5 постов с различным контентом.

### Запуск сервера

```bash
npm run dev  # режим разработки с hot reload
npm start    # production режим
```

Сервер запустится на `http://localhost:3001`

## Тестовые учетные данные

- **Администратор**: `admin` / `admin123`
- **SMM менеджер**: `smm_manager` / `smm123`
- **Пользователь**: `user` / `user123`

## API Endpoints

### Авторизация

- `POST /api/auth/login` - вход в систему
  ```json
  {
    "username": "admin",
    "password": "admin123"
  }
  ```
- `GET /api/auth/me` - получить текущего пользователя (требует токен)
- `POST /api/auth/logout` - выход из системы

### Пользователи

Все эндпоинты требуют заголовок `Authorization: Bearer <token>`

- `GET /api/users` - список всех пользователей
- `GET /api/users/:id` - пользователь по ID
- `POST /api/users` - создать пользователя
- `PATCH /api/users/:id` - обновить пользователя
- `DELETE /api/users/:id` - удалить пользователя

### Посты

- `GET /api/posts` - список всех постов (краткая информация)
- `GET /api/posts/:id` - полная информация о посте с JOIN (текст, теги, фото, видео, опросы, авторы)
- `POST /api/posts` - создать пост (требует авторизацию)
- `PATCH /api/posts/:id` - обновить пост (требует авторизацию)
- `DELETE /api/posts/:id` - удалить пост (требует авторизацию)

## Использование типов на фронтенде

Вы можете импортировать типы из общей папки `shared/types`:

```typescript
import type { UserDTO, PostDTO, PostDetailedDTO } from '../shared/types';
```

## Особенности

- **Авторизация**: Простая проверка заголовка `Authorization`. При логине возвращается фейковый JWT токен.
- **JOIN логика**: При запросе `GET /api/posts/:id` сервер автоматически собирает полный объект поста, объединяя данные из всех связанных таблиц.
- **Персистентность**: Все изменения сохраняются в `data/db.json` и доступны после перезапуска сервера.
- **Валидация**: Базовая валидация входных данных с понятными сообщениями об ошибках.
